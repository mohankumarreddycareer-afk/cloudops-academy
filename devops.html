INTERVIEW PRACTICE

DevOps Interview Questions

1. What is DevOps?

DevOps combines practices, collaboration and automation to improve software delivery and operations.

2. What is the difference between an image and a container?

A Docker image is a packaged template. A container is a running or stopped instance created from an image.

3. What is CI/CD?

Continuous Integration automates integrating and testing changes. Continuous Delivery or Deployment automates release preparation or deployment.

4. What is Infrastructure as Code?

IaC manages infrastructure using version-controlled configuration files instead of relying only on manual setup.

5. How do you troubleshoot a failed container?

Check container status, inspect configuration, review logs, verify ports and environment settings, and reproduce the failure safely.

docker ps -a
docker logs CONTAINER_ID
docker inspect CONTAINER_ID

COMMAND LINE

AWS CLI Basics

Install and configure AWS CLI using an authorized identity before running commands.

aws --version
aws sts get-caller-identity
aws s3 ls

What these do: Check the CLI version, identify the active AWS identity, and list accessible S3 buckets.

Never paste AWS access keys or secret keys into a public website or GitHub repository.

INTERVIEW PREPARATION

AWS Interview Questions

1. What is AWS?

AWS is a cloud platform offering compute, storage, networking, databases and many other services on demand.

2. What is the difference between EC2 and S3?

EC2 provides virtual compute capacity. S3 stores objects such as files, backups and logs.

3. What is a VPC?

A VPC is a logically isolated virtual network in AWS where you define IP ranges, subnets and routing.

4. What is IAM least privilege?

Grant only the permissions required to perform a task, and avoid unnecessary broad access.

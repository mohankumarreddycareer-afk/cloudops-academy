What is AWS?

AWS is a cloud platform that provides computing, storage, networking, databases and other services on demand.

What is DevOps?

DevOps combines collaboration, automation and engineering practices to improve software delivery and application operations.

What is Docker?

Docker is a platform used to build, package and run applications in containers.

What is CI/CD?

CI/CD automates steps such as integrating code, testing applications and preparing or deploying releases.

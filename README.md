
# CloudOps Academy 🚀

Learn AWS Cloud and DevOps through practical examples, hands-on projects, and interview preparation.

## 📌 About the Project

CloudOps Academy is a beginner-friendly learning website designed to help learners understand AWS services and DevOps tools with practical examples.

## 🎯 Learning Topics

### AWS Cloud
- AWS Cloud fundamentals
- IAM — Identity and Access Management
- EC2 — Virtual Servers
- S3 — Cloud Storage
- VPC — Virtual Private Cloud
- RDS — Relational Database Service
- Load Balancers and Auto Scaling
- Route 53 and AWS CLI

### DevOps Tools
- Git and GitHub
- Docker and Containers
- CI/CD Pipelines
- Terraform and Infrastructure as Code
- PowerShell Automation
- Monitoring and Troubleshooting
- Application Deployment

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub
- GitHub Pages

## 💻 Practical Projects

- AWS VPC and EC2 setup
- Public and private subnet architecture
- Docker containerization
- CI/CD pipeline fundamentals
- Infrastructure automation with Terraform
